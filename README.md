## 📌 Project Overview

I am excited to share that I have successfully completed my first project as part of the Cybersecurity Program at **Networkwalks (Batch B084)**.

In this project, I built a virtual cybersecurity testing lab using Oracle VirtualBox and Kali Linux. The primary goal was to understand virtualization, network configuration, and the fundamentals of setting up a secure testing environment.

## 🛠️ Tools & Technologies

- Oracle VirtualBox
- Kali Linux
- NAT Network
- Virtual Machine Networking

## 🎯 Tasks Completed

- ✅ Installed and configured VirtualBox.
- ✅ Imported and configured Kali Linux.
- ✅ Created a private NAT Network.
- ✅ Configured and verified Kali Linux network settings.
- ✅ Tested network connectivity.
- ✅ Verified DNS resolution.
- ✅ Created a clean VM snapshot for recovery.

## 📚 Key Learning Outcomes

Through this project, I gained practical experience in:

- Virtual Machine Configuration
- NAT vs. NAT Network
- IP Address Configuration
- Network Connectivity Testing
- DNS Resolution
- Virtual Machine Snapshots
- Technical Documentation
